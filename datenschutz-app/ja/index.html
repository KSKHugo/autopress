アプリのプライバシー

Hybrid AutoPress アプリのプライバシーポリシー

これは参考訳です。法的に有効なのはドイツ語版です。要点：AutoPress にはアカウントがなく、独自のサーバーを運用せず、分析・広告・トラッキングのサービスを含みません。アプリが通信するのはあなたの WordPress サイトと App Store だけで、他の誰とも通信しません。

このポリシーは iPhone、iPad、Mac 用アプリに関するものです。ウェブサイト hybrid-autopress.com には独自のプライバシーポリシーがあります。

2. まず要点

Hybrid AutoPress は、デバイス上の Markdown ファイルを、あなた自身が指定した WordPress サイトへ投稿や固定ページとしてアップロードします。開発者のもとにユーザーアカウントはなく、独自サーバーもなく、分析・広告・トラッキングのサービスもありません。開発者として、私があなたの書類、画像、認証情報、ウェブサイトにアクセスすることは一切ありません。

3. あなたの書類と画像

アプリが読むのはあなたが渡したものだけです：選択またはウインドウにドラッグした Markdown ファイルとフォルダ、その中や隣にある画像。Mac ではアプリはサンドボックス内で動作し、iPhone と iPad ではシステムのファイルアクセスが適用されます。写真ライブラリの写真は、システムの写真ピッカーで1枚ずつ選んだ場合にのみアプリに渡ります。アプリはライブラリの他の部分にアクセスできません。

Markdown から WordPress ブロックへの変換、画像の縮小、トリミング、クレジットの挿入は、すべてデバイス上で行われます。アップロード時には、テキスト、画像、あなたが設定した情報（タイトル、ステータス、日付、カテゴリー、タグ、抜粋、投稿者、SEO 項目、クレジット、代替テキスト）がデバイスから直接あなたの WordPress サイトへ送られ、そこではサイト運営者またはホスティング事業者のプライバシー規定が適用されます。アプリはセッションを超えて書類の内容を保持しません。

4. ウェブサイトと認証情報

ウェブサイトを接続する際、アプリはその WordPress REST API を呼び出します（サイトのアドレス、ユーザープロフィール、カテゴリー、タグ、投稿者、そしてサイトがどの項目を受け付けるかを知るための投稿スキーマなど）。ウェブサイトへの接続は https のみです。暗号化されていない接続は、自分のコンピュータ上のテスト環境（localhost）に対してのみ許可されます。

ブラウザでのログインでは、あなた自身のウェブサイトにログインし、WordPress が AutoPress 用のアプリケーションパスワードを作成します。ログインパスワードがアプリに渡ることはありません。あるいは、ユーザー名と自分で作成したアプリケーションパスワードを入力することもできます。WordPress.com の場合、ログインは Automattic のログインページで行われ、Automattic Inc. のプライバシーポリシーが適用されます。

アプリケーションパスワードとアクセストークンはデバイスのキーチェーンに保存され、設定やファイルには保存されず、それが属するウェブサイト以外には送信されません。各アプリケーションパスワードは WordPress のプロフィールで取り消せます。アプリの「ウェブサイトを管理」で、ウェブサイトとその認証情報をデバイスから削除できます。

5. デバイス上の設定

接続したウェブサイト（秘密情報を除く）、画像の設定、「投稿か固定ページか、下書きか公開か」の選択は、デバイス上のアプリの設定に保存されます。デバイスの外に出ることはなく、アプリを削除すると消えます。

6. サブスクリプションと無料試用期間（App Store）

AutoPress Pro のサブスクリプションは、すべて Apple の App Store（StoreKit）を通じて処理されます。購入、支払い、請求、更新、解約は Apple 自身のプライバシーポリシーに基づいて Apple が処理し、私はあなたの名前、住所、支払い情報を受け取りません。アプリは有効なサブスクリプションがあるかどうかを App Store に問い合わせるだけです。7日間の試用期間の開始日はデバイスのキーチェーンにローカル保存されます。

7. 開発者によるデータ収集はありません

AutoPress は開発者のサーバーと通信せず、第三者の分析やクラッシュレポートのサービスを含みません。クラッシュレポートは、あなたがデバイスの設定で診断データの共有を自ら許可した場合に限り、Apple 経由で匿名化された形で私に届くことがあります。

8. 外部へのリンク

あなたの操作によって、アプリはブラウザであなたのウェブサイトのページ（投稿の表示、WordPress での編集、プロフィールを開く）、Apple の利用規約、およびこのプライバシーポリシーを開きます。そのリンクをたどったときにはじめて、各提供者が独自の規定に基づいてデータを処理します。

9. あなたの権利

私が個人データを処理する場合（実際にはあなたがメールを送ってくださった場合のみ）、あなたには GDPR 第15条から第21条に基づく権利があります：アクセス、訂正、消去、制限、データポータビリティ、異議申し立て。

また、監督機関に苦情を申し立てる権利があります（GDPR 第77条）。私の管轄機関はラインラント＝プファルツ州データ保護・情報自由委員（Landesbeauftragter für den Datenschutz und die Informationsfreiheit Rheinland-Pfalz, Hintere Bleiche 34, 55116 Mainz, Germany）です。あなたの WordPress サイト上のデータについてはその運営者が、App Store のデータについては Apple が窓口です。

10. 最新の状態

バージョン：2026年9月。新機能などでアプリが変わった場合、このポリシーも更新されます。
