App 隐私

Hybrid AutoPress App 隐私政策

本文为参考译文，以德文版为准。简而言之：AutoPress 没有账户，不运营自己的服务器，不包含分析、广告或跟踪服务。App 只与你的 WordPress 网站和 App Store 通信，不与任何其他方通信。

本政策适用于 iPhone、iPad 和 Mac 上的 App。网站 hybrid-autopress.com 有自己的隐私政策。

2. 先说要点

Hybrid AutoPress 把你设备上的 Markdown 文件作为文章和页面上传到你自己指定的 WordPress 网站。开发者处没有用户账户，没有自己的服务器，也没有分析、广告或跟踪服务。作为开发者，我在任何时候都无法访问你的文稿、图片、凭据或网站。

3. 你的文稿和图片

App 只读取你提供的内容：你选择或拖入窗口的 Markdown 文件和文件夹，以及其中或旁边的图片。在 Mac 上 App 运行于沙盒中；在 iPhone 和 iPad 上适用系统的文件访问规则。只有当你在系统的照片选择器中逐张选择时，照片图库中的照片才会传给 App；App 无法访问你图库中的其他内容。

把 Markdown 转换为 WordPress 区块，以及图片的缩放、裁剪和署名，全部在你的设备上完成。上传时，文本、图片和你设置的信息（标题、状态、日期、分类、标签、摘要、作者、SEO 字段、署名、替代文本）从你的设备直接发送到你的 WordPress 网站，在那里适用网站运营者或托管商的隐私规定。App 不会在会话结束后保留你文稿的任何内容。

4. 网站与凭据

连接网站时，App 会调用其 WordPress REST API（包括网站地址、用户资料、分类、标签、作者以及文章架构，以了解网站接受哪些字段）。只通过 https 连接网站；未加密的连接仅允许用于你自己电脑上的测试安装（localhost）。

通过浏览器登录时，你登录的是自己的网站，WordPress 会为 AutoPress 创建一个应用程序密码；你的登录密码不会传给 App。你也可以输入用户名和自己创建的应用程序密码。对于 WordPress.com，登录在 Automattic 的登录页面进行，适用 Automattic Inc. 的隐私政策。

应用程序密码和访问令牌保存在设备的钥匙串中，从不放在设置或文件里，也不会传给它所属网站以外的任何一方。每个应用程序密码都可以在你的 WordPress 个人资料中撤销；App 中的“管理网站”会把网站及其凭据从设备中删除。

5. 设备上的设置

已连接的网站（不含秘密信息）、图片设置以及“文章或页面、草稿或发布”的选择保存在你设备上的 App 设置中。它们从不离开设备，删除 App 时一并移除。

6. 订阅与免费试用（App Store）

AutoPress Pro 订阅完全通过 Apple 的 App Store（StoreKit）处理。购买、付款、账单、续订和取消均由 Apple 依照其自身隐私政策处理；我不会收到你的姓名、地址或支付信息。App 只向 App Store 询问是否存在有效订阅。七天试用的开始时间保存在你设备的钥匙串中。

7. 开发者不收集数据

AutoPress 不连接开发者的服务器，也不包含第三方的分析或崩溃报告服务。崩溃报告至多以匿名形式通过 Apple 送达我，且仅当你自己在设备设置中允许共享诊断数据时。

8. 对外链接

在你的操作下，App 会在浏览器中打开你网站的页面（查看文章、在 WordPress 中编辑、打开个人资料），以及 Apple 的使用条款和本隐私政策。只有当你点击这样的链接时，相应的提供方才会按其自身规定处理数据。

9. 你的权利

在我处理个人数据的范围内（实际上只有当你给我发电子邮件时），你享有 GDPR 第 15 至 21 条规定的权利：访问、更正、删除、限制、数据可携带和反对。

你还有权向监管机构投诉（GDPR 第 77 条）；对我负责的机构是莱茵兰-普法尔茨州数据保护与信息自由专员（Landesbeauftragter für den Datenschutz und die Informationsfreiheit Rheinland-Pfalz，Hintere Bleiche 34，55116 Mainz，德国）。你 WordPress 网站上的数据请联系其运营者；App Store 中的数据请联系 Apple。

10. 更新

版本：2026 年 9 月。如果 App 发生变化，例如新增功能，本政策将随之更新。
