适用于 iPhone、iPad 和 Mac

放进一个 Markdown 文件夹。得到一个 WordPress 网站。

Hybrid AutoPress 一次把许多 Markdown 文件上传到 WordPress。每个文件成为一篇文章或一个页面，保留标题、链接、列表、表格和图片，可存为草稿、立即发布或定时发布。

即将登陆 App Store 看看它怎么用

步骤 1

添加文件。或者整个文件夹。

选择单个文件、含子文件夹的整个文件夹，或把所有内容拖进窗口。AutoPress 从 front matter、第一个标题或文件名读取标题，并自动找到特色图片。

步骤 2

决定一次。需要时单独调整。

文章还是页面；草稿、立即发布还是定时：为所有文稿设置一次，再对任意一篇单独修改。整批可以错开时间，第一篇在某个日期，其余每天一篇。在有内容立即上线之前，AutoPress 会确认一次。

步骤 3

按下上传。看着它完成。

文稿一篇接一篇在 WordPress 中创建，图片先行。进度条显示进展，随时可以停止；已上传的内容保持不变。

步骤 4

完成。附带返回链接。

每篇完成的文稿都有绿色对勾，以及在网站上查看或在 WordPress 中继续编辑的链接。如果出错，AutoPress 会告诉你原因和解决办法，并在下次重新发送。

送达的内容

真正的区块。不是一整坨。

你的 Markdown 以 WordPress 区块编辑器的区块形式送达，而不是一个无法拆分的大块。每个标题、段落、列表、引用、表格和图片都是独立区块，可以单独编辑、移动或删除。

  • 每个元素一个区块各级标题，含粗体、斜体、代码和链接的段落，有序和嵌套列表，任务列表，引用，代码块和分隔线。
  • 表格和图片，货真价实Markdown 表格成为保留对齐方式的表格区块。图片成为带替代文本和说明的图片区块；带链接的图片保留链接。
  • 为 AI 工具的文本而生来自 ChatGPT、Claude 等的 Markdown 原样送达。生成文本中常见的、单独落在一行的 **，会像在 Hybrid 中一样被悄悄修复。

图片

你的图片一同上传。

再也不用手动上传图片、修补链接。Markdown 文件旁边的图片会随之进入 WordPress：缩放到网页尺寸，按你的意愿裁剪，角落里加上你的名字。

  • 进入媒体库正文中的本地图片连同替代文本一起上传并在文章中链接。无论多少篇文稿使用，每张图片在每个网站、每次会话只上传一次。
  • 网页尺寸，JPEG 或 WebP上传前缩小，从不放大：长边 1200、1600、2000 或 2560 像素。iPhone 的 HEIC 照片自动转换；带透明的图片保持 PNG。
  • 裁剪每张图片16:9、3:2、4:3、1:1、4:5、2:3 或 9:16。在取景框下移动图片，双指缩放，所选范围以完整尺寸送达。
  • 角落里的署名在每张上传图片的右下角加上“© 名字”，沿底边或沿右边向上，白色或黑色，字号自选，实时预览。
  • 特色图片，自动找到在 front matter 中指定，或把同名图片放在文件旁边：lisbon.md → lisbon.jpg。也可以自己选择文件或照片。

定时发布

今天上传。整月陆续上线。

五十篇文稿不必同一天出现。现在上传，让 WordPress 在你选定的时间自动发布。

  • 草稿、立即或定时草稿是默认设置，从不公开显示。立即发布在上传后即刻上线。定时为每篇文稿设定日期和时间。
  • 整批错开时间“第一篇在”某个日期，“之后每隔”一小时、三小时、一天、两天或一周。五十篇文稿变成一份编辑日程；单篇的日期之后仍可修改。
  • 你的时间，你的时钟时间以你的设备显示为准，与网站设置的时区无关。文件 front matter 中的未来日期会定时发布；过去的日期会回溯日期。

元数据与搜索引擎

文章需要的一切。从你的网站读取。

没有任何东西是为某个特定安装量身定制的。AutoPress 询问每个网站有什么，并且只显示这些。

  • 来自你网站的分类和标签从网站自己的列表中选择，常用的排在前面，为拥有数千标签的网站提供搜索。新的直接输入，上传文稿时自动创建。一次选择可应用到所有文稿。
  • 适配你所用插件的 SEO 字段Yoast SEO、Rank Math、SEOPress 和 Jetpack 的 SEO 标题、元描述和焦点关键词，附带搜索结果可显示长度的计数器。在 App 中或 front matter 中设置。
  • 作者、评论、置顶固定链接别名、摘要，若账户可代他人发布则可选作者，是否开放评论，以及文章是否置顶。
  • 网站自身的字段插件或主题向 App 开放的字段，如副标题、社交网络分享文案，会自动出现，并用通俗的语言说明。

一个 App，三种设备

在书桌前。或在沙发上。

iPhone、iPad 和 Mac 上是同一个 App，一次购买三处可用。从文件所在的任何地方上传：iCloud 云盘、“文件”App 或 Mac 上的文件夹。

Front matter

顶部加几行。如果你愿意。

可选的 front matter，就像 Jekyll、Hugo 和 Obsidian 写的那样，逐个文件控制一切。没有它，第一个标题就成为文章标题，且不会在正文中重复出现。文件中的一切只是初始值，在 App 中仍可修改。

  • WordPress 需要的一切title、type、status、date、slug、excerpt、tags、categories、author、comments、sticky、featured_image 及其替代文本。
  • 图片和搜索引擎也一样该文稿图片的 credit；供 SEO 插件使用的 seo_title、meta_description 和 focus_keyword。
  • 直接来自你的写作工具来自 Hybrid、Obsidian、iA Writer 或静态网站生成器的文件可以原样使用。AutoPress 读取 .md、.markdown、.mdown、.mkd 和 .mdwn。

你的 WordPress

适用于你的 WordPress。无论托管在哪里。

通过浏览器登录，WordPress 自己就会为 App 创建一个应用程序密码。你的登录密码永远不会传给 AutoPress，访问权限可随时在个人资料中撤销。WordPress.com 网站以同样方式连接。任何可通过 https 访问的 WordPress 5.6 或更高版本。

凭据保存在钥匙串中

从不放在设置里，从不放在文件中。只通过 https 连接网站；未加密的连接不会发送任何内容。

出错时有出路

如果你的服务器吞掉了登录信息（共享主机上很常见），AutoPress 会识别出来，并显示能解决问题的 .htaccess 行。挡路的安全插件会被点名。

只与你的网站通信

无需账户，没有跟踪，没有中间服务器。文稿和图片从你的设备直接到你的 WordPress。

内置帮助

从第一步到故障排除的十四个简短主题，覆盖全部九种语言，此外在需要的地方都有提示：字段下方、登录时、每条错误旁。
