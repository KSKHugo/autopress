iPhone、iPad、Mac のために

Markdown のフォルダを入れる。WordPress サイトが出てくる。

Hybrid AutoPress は、たくさんの Markdown ファイルを一度に WordPress へアップロードします。各ファイルは見出し、リンク、リスト、表、画像をそのままに投稿または固定ページになり、下書きとして保存、すぐに公開、または後日の予約公開ができます。

まもなく App Store に登場 使い方を見る

ステップ 1

ファイルを追加。フォルダごとでも。

ファイルを個別に選ぶか、サブフォルダを含むフォルダを選ぶか、ウインドウにまとめてドラッグ。AutoPress はタイトルをフロントマター、最初の見出し、またはファイル名から読み取り、アイキャッチ画像も自動で見つけます。

ステップ 2

一度決めて、必要なところだけ変える。

投稿か固定ページか、下書き・すぐに公開・予約か：全書類に一度設定して、個々の書類で上書きできます。まとめて時間差をつけることも可能。最初の1件の日付を決め、残りは1日ずつずらす。すぐに公開する前には、AutoPress が一度だけ確認します。

ステップ 3

アップロードを押して、見守る。

書類は WordPress に1件ずつ作成されます。画像が先です。進捗バーで状況がわかり、いつでも停止できます。アップロード済みのものはそのまま残ります。

ステップ 4

完了。戻るリンク付き。

完了した書類には緑のチェックと、サイトで表示するリンク、WordPress で編集を続けるリンクが付きます。失敗した場合は、AutoPress が原因と対処法を伝え、次回に再送します。

届くもの

本物のブロック。かたまりではなく。

Markdown は WordPress ブロックエディターのブロックとして届きます。分割できない大きなかたまりではありません。見出し、段落、リスト、引用、表、画像のひとつひとつが独立したブロックで、個別に編集・移動・削除できます。

  • 要素ごとにひとつのブロック各レベルの見出し、太字・斜体・コード・リンクを含む段落、番号付きリストと入れ子のリスト、タスクリスト、引用、コードブロック、区切り線。
  • 表と画像も本物Markdown の表は配置を保ったまま表ブロックになります。画像は代替テキストとキャプション付きの画像ブロックに。リンク付きの画像はリンクを保ちます。
  • AI ツールの文章のためにChatGPT や Claude などの Markdown はそのまま届きます。生成テキストによくある、1行に取り残された ** は、Hybrid と同じように静かに修復されます。

画像

画像も一緒に。

画像を手作業でアップロードしてリンクを直す手間はもう不要です。Markdown ファイルの隣にあるものは、ウェブ向けサイズに縮小され、好きなようにトリミングされ、隅に名前を入れて、一緒に WordPress に届きます。

  • メディアライブラリへ本文中のローカル画像は代替テキスト付きでアップロードされ、投稿にリンクされます。何件の書類で使っても、サイトとセッションごとに1回だけ。
  • ウェブサイズ、JPEG または WebPアップロード前に縮小、拡大はしません：長辺 1200、1600、2000、2560 ピクセル。iPhone の HEIC 写真は変換。透明部分のある画像は PNG のまま。
  • すべての画像をトリミング16:9、3:2、4:3、1:1、4:5、2:3、9:16。枠の下で画像を動かし、2本指でズーム。選んだ範囲がフルサイズで届きます。
  • 隅にクレジット「© 名前」をアップロードする各画像の右下に。下辺に沿って、または右辺を上向きに、白または黒で、好きな大きさで、ライブプレビュー付き。
  • アイキャッチ画像は自動検出フロントマターで指定するか、同名の画像をファイルの隣に置くだけ：lisbon.md → lisbon.jpg。ファイルや写真を自分で選ぶこともできます。

予約公開

今日アップロード。ひと月かけて公開。

50件の書類を同じ日に公開する必要はありません。今アップロードして、あなたが決めた日時に WordPress が自動で公開します。

  • 下書き、すぐに、予約下書きが初期設定で、何も公開しません。「すぐに公開」はアップロードと同時に公開。「予約」は書類ごとに日時を設定します。
  • まとめて時間差をつける「最初の1件を」ある日に、「以降は」1時間、3時間、1日、2日、1週間ごと。50件の書類が編集カレンダーになります。個々の日時は後から変更できます。
  • あなたの時刻、あなたの時計時刻はデバイスに表示されるもの。ウェブサイトのタイムゾーン設定は関係ありません。フロントマターの未来の日付は予約に、過去の日付は日付のさかのぼりになります。

メタデータと検索エンジン

投稿に必要なすべてを。あなたのサイトから読み取って。

特定のインストールに合わせたものは何もありません。AutoPress はそれぞれのウェブサイトに何があるかを尋ね、ちょうどそれを表示します。

  • サイトのカテゴリーとタグサイト自身の一覧から選択。よく使うものが先頭に、数千のタグがあるサイトのために検索付き。新しいものは入力すれば、アップロード時に作成されます。1つの選択を全書類に適用することもできます。
  • お使いのプラグインの SEO 項目Yoast SEO、Rank Math、SEOPress、Jetpack 向けの SEO タイトル、メタディスクリプション、フォーカスキーフレーズ。検索結果の表示幅に合わせた文字数カウンター付き。アプリでもフロントマターでも設定できます。
  • 投稿者、コメント、先頭固定パーマリンクのスラッグ、抜粋、他人名義で公開できるアカウントなら投稿者、コメントを受け付けるか、投稿をブログの先頭に固定するか。
  • ウェブサイト独自の項目プラグインやテーマがアプリに公開している項目、サブタイトルや SNS 向けメッセージなどが自動で表示され、わかりやすく説明されます。

1つのアプリ、3つのデバイス

デスクで。ソファでも。

iPhone、iPad、Mac で同じアプリ。1回の購入で3つすべてに。iCloud Drive、ファイルアプリ、Mac のフォルダなど、ファイルのある場所からアップロードできます。

フロントマター

先頭に数行。お好みで。

Jekyll、Hugo、Obsidian が書くような任意のフロントマターで、ファイルごとにすべてを制御できます。なければ最初の見出しがタイトルになり、投稿内に重複して現れません。ファイルの内容はあくまで初期値で、アプリで変更できます。

  • WordPress に必要なすべてtitle、type、status、date、slug、excerpt、tags、categories、author、comments、sticky、featured_image とその代替テキスト。
  • 画像と検索エンジンもその書類の画像用の credit、SEO プラグイン用の seo_title、meta_description、focus_keyword。
  • お使いの執筆ツールから直接Hybrid、Obsidian、iA Writer、静的サイトジェネレーターのファイルがそのまま使えます。AutoPress は .md、.markdown、.mdown、.mkd、.mdwn を読み取ります。

# 任意：どの行も省略可

type: post
status: scheduled

認証情報はキーチェーンに

設定にもファイルにも保存しません。ウェブサイトへの接続は https のみ。暗号化されていない接続では何も送信しません。

エラーには出口を

共用ホスティングでよくあるように、サーバーがログイン情報を落としてしまう場合、AutoPress はそれを検知し、解決する .htaccess の行を表示します。邪魔をしているセキュリティプラグインは名前で示します。

話す相手はあなたのサイトだけ

アカウント不要、トラッキングなし、中継サーバーなし。書類と画像はデバイスから直接あなたの WordPress へ。
