Problemi comuni

“L'autenticazione non è arrivata a WordPress.”

Il server web scarta l'autenticazione prima che WordPress la veda; succede spesso con l'hosting condiviso. Aggiungi questa riga al file .htaccess nella cartella di WordPress e collegati di nuovo:

SetEnvIf Authorization "(.*)" HTTP_AUTHORIZATION=$1

“Le password applicazione non sono disponibili su questo sito.”

Richiedono WordPress 5.6 o successivo e https. Plugin di sicurezza come Wordfence le disattivano per impostazione predefinita; consentile nelle impostazioni del plugin.

“WordPress è stato trovato, ma la sua API REST è disattivata o bloccata.”

Un plugin di sicurezza o una regola del server blocca /wp-json/. Deve essere raggiungibile per gli utenti connessi; controlla le impostazioni REST API del plugin o chiedi al tuo provider.

“Nome utente o password applicazione errati.”

Usa una password applicazione (Utenti → Profilo → Password applicazione), non la tua password di accesso. Oppure scegli l'accesso dal browser e WordPress ne crea una per te.

Un'immagine è più grande di quanto il sito accetta

Scegli un lato lungo più piccolo nelle impostazioni delle immagini (riga Immagini dell'elenco, sul Mac ⌘,) o aumenta il limite di caricamento presso il tuo provider.

Ripristinare o gestire AutoPress Pro

Apri la finestra Pro e scegli “Ripristina acquisti” su un nuovo dispositivo con lo stesso Apple Account, oppure “Gestisci abbonamento” per modificarlo o disdirlo.

Disdetta e rimborsi

L'abbonamento passa dall'App Store. Si disdice in qualsiasi momento nelle impostazioni del tuo Apple Account; i rimborsi li gestisce Apple su reportaproblem.apple.com.

L'app ha un proprio aiuto con quattordici argomenti brevi: sul Mac in Aiuto → Aiuto AutoPress (⌘?), su iPhone e iPad dietro il punto interrogativo in cima all'elenco. Cosa fa AutoPress · Privacy dell'app
