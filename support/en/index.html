Support for Hybrid AutoPress

Questions, problems or requests? Write to me; I answer every message myself. Many connection problems have a quick fix, listed below.

What helps me help you

  • Your device and system version (iPhone, iPad or Mac; iOS, iPadOS or macOS).
  • The app version: on the Mac under Hybrid AutoPress → About Hybrid AutoPress.
  • Your WordPress version and your host, and any security or SEO plugins.
  • The exact message the app showed, and the steps that led to it. A screenshot is welcome.

Common problems

“The sign-in did not reach WordPress.”

The web server drops the sign-in before WordPress sees it; this is common with shared hosting. Add this line to the .htaccess file in your WordPress folder, then connect again:

SetEnvIf Authorization "(.*)" HTTP_AUTHORIZATION=$1

“Application passwords are not available on this website.”

They need WordPress 5.6 or later and https. Security plugins such as Wordfence switch them off by default; allow them in the plugin's settings.

“WordPress was found, but its REST API is switched off or blocked.”

A security plugin or a server rule blocks /wp-json/. It must be reachable for signed-in users; check the plugin's REST API settings or ask your host.

“User name or application password are wrong.”

Use an application password (Users → Profile → Application Passwords), not your normal login password. Or choose “Sign In via Browser”, and WordPress creates one for you.

A picture is larger than the website accepts

Choose a smaller longest edge in the image settings (Images in the list, on the Mac ⌘,), or raise the upload limit at your host.

Restore or manage AutoPress Pro

Open the Pro window and choose “Restore Purchases” on a new device with the same Apple Account, or “Manage Subscription” to change or cancel it.

Cancellation and refunds

The subscription runs through the App Store. It can be cancelled at any time in your Apple Account settings; refunds are handled by Apple at reportaproblem.apple.com.
