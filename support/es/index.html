Problemas frecuentes

«La autenticación no llegó a WordPress.»

El servidor web descarta la autenticación antes de que WordPress la vea; es habitual en alojamientos compartidos. Añade esta línea al archivo .htaccess de tu carpeta de WordPress y vuelve a conectar:

SetEnvIf Authorization "(.*)" HTTP_AUTHORIZATION=$1

«Las contraseñas de aplicación no están disponibles en este sitio.»

Necesitan WordPress 5.6 o posterior y https. Los plugins de seguridad como Wordfence las desactivan por defecto; permítelas en los ajustes del plugin.

«Se encontró WordPress, pero su API REST está desactivada o bloqueada.»

Un plugin de seguridad o una regla del servidor bloquea /wp-json/. Debe ser accesible para usuarios conectados; revisa los ajustes de REST API del plugin o consulta a tu proveedor.

«El nombre de usuario o la contraseña de aplicación son incorrectos.»

Usa una contraseña de aplicación (Usuarios → Perfil → Contraseñas de aplicación), no tu contraseña normal. O elige iniciar sesión con el navegador y WordPress creará una por ti.

Una imagen es mayor de lo que acepta el sitio

Elige un lado largo menor en los ajustes de imagen (fila Imágenes de la lista, en el Mac ⌘,) o aumenta el límite de subida en tu proveedor.

Restaurar o gestionar AutoPress Pro

Abre la ventana Pro y elige «Restaurar compras» en un dispositivo nuevo con el mismo Apple Account, o «Gestionar suscripción» para cambiarla o cancelarla.

Cancelación y reembolsos

La suscripción va por el App Store. Se cancela cuando quieras en los ajustes de tu Apple Account; los reembolsos los gestiona Apple en reportaproblem.apple.com.
