Problèmes fréquents

« L'authentification n'est pas parvenue à WordPress. »

Le serveur web perd l'authentification avant que WordPress ne la voie ; c'est fréquent en hébergement mutualisé. Ajoutez cette ligne au fichier .htaccess de votre dossier WordPress, puis reconnectez-vous :

SetEnvIf Authorization "(.*)" HTTP_AUTHORIZATION=$1

« Les mots de passe d'application ne sont pas disponibles sur ce site. »

Ils nécessitent WordPress 5.6 ou plus et https. Des extensions de sécurité comme Wordfence les désactivent par défaut ; autorisez-les dans les réglages de l'extension.

« WordPress a été trouvé, mais son API REST est désactivée ou bloquée. »

Une extension de sécurité ou une règle du serveur bloque /wp-json/. Il doit être accessible aux utilisateurs connectés ; vérifiez les réglages REST API de l'extension ou demandez à votre hébergeur.

« L'identifiant ou le mot de passe d'application est incorrect. »

Utilisez un mot de passe d'application (Utilisateurs → Profil → Mots de passe d'application), pas votre mot de passe habituel. Ou choisissez la connexion via le navigateur : WordPress en crée un pour vous.

Une image dépasse la taille acceptée par le site

Choisissez un grand côté plus petit dans les réglages d'images (ligne Images de la liste, sur Mac ⌘,) ou augmentez la limite d'envoi chez votre hébergeur.

Restaurer ou gérer AutoPress Pro

Ouvrez la fenêtre Pro et choisissez « Restaurer les achats » sur un nouvel appareil avec le même compte Apple, ou « Gérer l'abonnement » pour le modifier ou le résilier.

Résiliation et remboursement

L'abonnement passe par l'App Store. Il se résilie à tout moment dans les réglages de votre compte Apple ; les remboursements sont traités par Apple sur reportaproblem.apple.com.
