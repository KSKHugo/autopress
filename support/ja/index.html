よくある問題

「認証情報がWordPressに届きませんでした。」

ウェブサーバーが WordPress に渡す前に認証情報を落としています。共用ホスティングでよくあります。WordPress フォルダの .htaccess ファイルに次の行を追加して、もう一度接続してください：

SetEnvIf Authorization "(.*)" HTTP_AUTHORIZATION=$1

「このウェブサイトではアプリケーションパスワードが利用できません。」

WordPress 5.6 以降と https が必要です。Wordfence などのセキュリティプラグインは初期設定で無効にします。プラグインの設定で許可してください。

「WordPressは見つかりましたが、REST APIが無効化またはブロックされています。」

セキュリティプラグインかサーバーのルールが /wp-json/ をブロックしています。ログイン中のユーザーがアクセスできる必要があります。プラグインの REST API 設定を確認するか、ホスティング事業者にお問い合わせください。

「ユーザー名またはアプリケーションパスワードが正しくありません。」

通常のログインパスワードではなく、アプリケーションパスワード（ユーザー → プロフィール → アプリケーションパスワード）を使ってください。または「ブラウザでログイン」を選ぶと、WordPress が自動で作成します。

画像がサイトの上限より大きい

画像設定（リストの「画像」、Mac では ⌘,）で長辺を小さくするか、ホスティング事業者でアップロード上限を引き上げてください。

AutoPress Pro の復元・管理

Pro ウインドウを開き、同じ Apple Account の新しいデバイスでは「購入を復元」を、変更や解約には「サブスクリプションを管理」を選んでください。

解約と返金

サブスクリプションは App Store 経由です。Apple Account の設定でいつでも解約できます。返金は Apple が reportaproblem.apple.com で受け付けています。
