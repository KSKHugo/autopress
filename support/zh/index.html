常见问题

“登录信息未到达 WordPress。”

Web 服务器在 WordPress 看到之前丢弃了登录信息；这在共享主机上很常见。请在 WordPress 文件夹的 .htaccess 文件中加入这一行，然后重新连接：

SetEnvIf Authorization "(.*)" HTTP_AUTHORIZATION=$1

“此网站不支持应用程序密码。”

需要 WordPress 5.6 或更高版本以及 https。Wordfence 等安全插件默认会关闭它们；请在插件设置中允许。

“找到了 WordPress，但其 REST API 已关闭或被阻止。”

某个安全插件或服务器规则阻止了 /wp-json/。它必须对已登录用户可访问；请检查插件的 REST API 设置或咨询托管商。

“用户名或应用程序密码错误。”

请使用应用程序密码（用户 → 个人资料 → 应用程序密码），而不是普通登录密码。或者选择通过浏览器登录，WordPress 会为你创建一个。

图片超过了网站接受的大小

在图片设置中选择更小的长边（列表中的“图片”一行，Mac 上 ⌘,），或在托管商处提高上传限制。

恢复或管理 AutoPress Pro

打开 Pro 窗口，在使用同一 Apple 账户的新设备上选择“恢复购买”，或选择“管理订阅”来更改或取消。

取消与退款

订阅通过 App Store 进行。可随时在 Apple 账户设置中取消；退款由 Apple 在 reportaproblem.apple.com 处理。
